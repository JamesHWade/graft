# Public Tempest artifact adoption

This consumer proof calls Tempest's installed public research publisher, reader
and admission functions over Graft's supported local artifact store, selections
and decision journal. It does not use the experimental metadata drivers or
reimplement decision persistence in a host script.

Run `Rscript tools/experiments/tempest-artifact-adoption/run.R` after the normal
pinned setup. The full suite includes this command. It executes Tempest's shipped
offline `examples/artifact-research.R` with independently pinned promotion bundles
from synthetic completed research products.

The proof retains complete claim/support/span/source contents, exact source
bodies, program provenance and readable synthesis. It checks a distinct review
of unchanged content, a corrected selection, historical report inspection,
withdrawal, and an identical retry that cannot reinstate eligibility. Tempest's
package tests additionally cover new-run admission, fresh-process inspection,
Co-STORM resume, STORM resume, current host policy and malformed selections.

Tempest owns scientific validation and the host supplies current access policy.
Graft owns immutable content, selection integrity and decision history. Neither
this offline example nor its passing tests prove Reader isolation, permanent
Forget, active-task cancellation or production durability. Native graph paths
remain pending retirement under #74; no compatibility shim is introduced.
